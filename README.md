#  Coffee Time - Interactive Coffee Shop Landing Page

A modern, responsive landing page for a coffee shop featuring dynamic menu filtering, shopping cart functionality, and smooth user interactions. Built with HTML, CSS, and vanilla JavaScript.

##  Features

- **Dynamic Menu System**: Menu items are loaded from a JavaScript data array
- **Category Filtering**: Filter by Hot Coffee, Cold Drinks, and Pastries
- **Shopping Cart**: Functional cart counter with visual feedback
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
- **Modern UI/UX**: Clean design with smooth animations and transitions
- **CSS Grid Layout**: Professional grid system for menu cards
- **Smooth Scrolling**: Navigation links scroll smoothly to sections

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Flexbox, Grid, Media Queries for responsiveness
- **JavaScript (ES6+)** - Dynamic content rendering, filtering logic, cart functionality

##  Key Functionalities

### Menu Filtering
Users can filter menu items by category:
- All items
- Hot Coffee
- Cold Drinks  
- Pastries

### Shopping Cart
- Click "Add to Cart" button on any item
- Cart counter updates in real-time
- Visual animation feedback when adding items
